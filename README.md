# Dart·Flutter 기초 14주

List까지 아는 사람이 하루 1시간씩 공부해서, 작은 Flutter 앱을 혼자 만들 수 있게 되는 과정이에요.

## 알고 있다고 보는 것

- 변수(`var`, `final`, `int`, `double`, `String`, `bool`)와 `print`
- 문자열 보간: `'$name'`, `'${a + b}'`
- 조건(`if`, `else`), 반복(`for`, `for-in`, `while`)
- 함수 만들고 부르기: `int add(int a, int b) { return a + b; }`
- List: `[1, 2, 3]`, `list[0]`, `list.length`, `list.add(4)`

이 중에 모르는 게 있으면 먼저 말해 주세요. 그 부분부터 보충해요.

## 하루 공부 순서 (1시간)

1. 그날 파일을 열고 맨 위 **예제**를 실행해요. 한 줄씩 설명을 읽어요. (15분)
2. **1단계 → 2단계 → 3단계** 순서로 풀어요. 단계마다 저장하고 실행해서 `[예상 출력]`과 비교해요. (40분)
3. 파일 맨 아래 `[내 말로 설명]` 질문에 소리 내어 답해요. (5분)

### 단계마다 하는 일

| 단계 | 하는 일 |
| --- | --- |
| 1단계 따라 하기 | 예제와 같은 모양으로, 값만 바꿔서 직접 써요 |
| 2단계 직접 작성 | 무엇을 만들지만 보고 처음부터 직접 짜요 |
| 3단계 읽고 예측 | 주어진 코드를 읽고, **실행하기 전에** 출력을 맞혀요 |

3단계는 처음에 `main`에서 `// step3();`로 꺼져 있어요. `[내 예측]`을 다 적은 뒤에 `//`를 지우고 실행해요. 미리 출력이 보이지 않게 하려는 거예요.
